# Student Attendance Analysis Using Python

## Project Overview
The Student Attendance Analysis project focuses on analysing student attendance records using Python. It helps understand students' attendance patterns, calculate attendance percentages, identify students with low attendance, and compare attendance across different classes.

The project uses data analysis and visualisation techniques to present attendance information in a clear and understandable way.

## Objectives
- Analyse student attendance records.
- Calculate attendance percentages.
- Identify the number of classes attended and missed.
- Compare average attendance across different classes.
- Categorise students based on the 75% attendance threshold.
- Identify students with the highest and lowest attendance.
- Present findings through graphs and charts.

## Dataset Information
The project uses a sample student attendance dataset containing **30 student records** and 7 columns:

- Student ID
- Student Name
- Class
- Total Classes
- Classes Attended
- Classes Missed
- Data Type

The dataset is used to perform attendance calculations and statistical analysis.

## Technologies Used
- **Python** – Programming language
- **Google Colab** – Development environment
- **Pandas** – Data handling and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualisation
- **Seaborn** – Statistical graphs and charts

## Project Workflow

1. Import the required Python libraries.
2. Upload and load the attendance dataset.
3. Explore the dataset using `head()`, `tail()`, `info()`, and `describe()`.
4. Check missing values and duplicate records.
5. Clean the dataset and remove invalid records.
6. Calculate attendance percentages and missed classes.
7. Perform statistical analysis.
8. Create graphs and visualisations.
9. Compare attendance across different classes.
10. Categorise and rank students based on attendance.

## Data Analysis and Visualisation
The project includes:
- Student attendance distribution histogram.
- Classes missed distribution.
- Attendance boxplot.
- Class-wise average attendance bar chart.
- Classes attended vs. attendance percentage scatter plot.
- Total classes vs. missed classes scatter plot.
- Attendance correlation heatmap.
- Attendance category pie chart.
- Top 10 and bottom 10 student rankings.

## Key Observations
- The dataset contains 30 student records.
- Each student has a total of 60 classes.
- Average classes attended are 48.5.
- Average classes missed are 11.5.
- The analysis categorises attendance as satisfactory (75% or above) or below 75%.

## Conclusion
This project demonstrates how Python can be used to clean, analyse, and visualise student attendance data. It provides useful insights into attendance patterns and helps identify students who may need to improve their attendance.
